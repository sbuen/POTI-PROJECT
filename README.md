# POTI Project

Página web para calouros universitários da área de TI que ainda não sabem em qual carreira seguir. O projeto reúne, de forma simples e objetiva, as principais áreas do mercado de tecnologia para ajudar o futuro profissional a escolher o seu foco.

## Áreas apresentadas

- **Desenvolvimento de Software**
- **Ciência de Dados**
- **Computação em Nuvem**
- **Segurança da Informação**

## Objetivo

Esclarecer dúvidas sobre onde atuar no mercado de TI, mostrando um panorama de cada área para quem está começando a graduação.

## Tecnologias utilizadas

- HTML
- CSS
- VS Code
- Claude (IA), como apoio no desenvolvimento

## Como executar

1. Clone o repositório:
   `git clone https://github.com/sbuen/POTI-PROJECT.git`
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` no navegador.

## Contexto

Projeto desenvolvido durante a graduação em Tecnologia em Análise e Desenvolvimento de Sistemas e apresentado na faculdade.
